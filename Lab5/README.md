# Lab 5: Parallel Skeletons

## Objective
The objective of this lab is to implement and understand standard parallel skeletons (algorithmic patterns) using Python. These patterns abstract common parallel operations.

## Tasks
- **task1_map.py**: Implementation of the `Map` skeleton.
- **task2_reduce.py**: Implementation of the `Reduce` skeleton.
- **task3_scan.py**: Implementation of the `Scan` (Prefix Sum) skeleton.
- **task4_merge_sort.py**: Parallel Merge Sort using splitting patterns.
- **task5_wavefront_lcs.py**: Wavefront parallelism for Longest Common Subsequence (LCS).

## Key Concepts
- Parallel Skeletons (Map, Reduce, Scan).
- Recursive Parallelism (Divide and Conquer).
- Dependency Analysis for Wavefront Patterns.

## How to Run
Run each task using Python:
```bash
python task1_map.py
```
