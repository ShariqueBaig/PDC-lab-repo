# Lab 7: GPGPU Programming

## Objective
This lab explores General-Purpose Graphics Processing Unit (GPGPU) programming, focusing on offloading computational tasks to the GPU for massive parallelism.

## Contents
- **Code/**: Subdirectory containing C++/OpenCL/CUDA source code for GPU tasks.
- **Lab 7 Report - Sharique Baig.md**: Comprehensive lab report with performance graphs and analysis.
- **output.png**: Visualization of output from GPGPU simulations (e.g., Reaction-Diffusion).

## Key Concepts
- Heterogeneous Computing (CPU + GPU).
- GPU Memory Hierarchy (Global, Local, Private).
- Offloading computational kernels.
- Reaction-Diffusion models.

## How to Run
Check the `Code/` directory for specific batch files (`run_gpgpu_reaction_diffusion.bat`, `run_gpgpu_reductions.bat`) that automate the execution on Windows.
