# Lab 8: CUDA Programming

## Objective
This lab focuses specifically on NVIDIA's CUDA platform for parallel computing on GPUs. It involves writing and optimizing CUDA kernels for high-performance tasks.

## Contents
- **Lab 8 - CUDA Programming.ipynb**: Jupyter Notebook containing CUDA code cells and performance analysis.
- **Sharique_28369_Lab8_CUDA_Report.pdf**: Detailed report of CUDA task implementations and speedup measurements.

## Key Concepts
- CUDA Kernel Definition (`__global__`).
- Block and Grid dimensions.
- Memory allocation on GPU (`cudaMalloc`, `cudaMemcpy`).
- Performance profiling of GPU kernels.

## Requirements
- NVIDIA GPU with CUDA support.
- CUDA Toolkit installed.
- Python with `pycuda` or similar libraries if using the notebook interface.
