# Lab 2: Multi-threading and Shared Memory

## Objective
The objective of this lab is to understand the basics of multi-threading and shared memory parallelism using Python. It explores how to create threads, manage shared state, and analyze performance.

## Contents
- **Lab 2 - Threads.ipynb**: The primary Jupyter Notebook containing the implementation and analysis of multi-threaded programs.
- **sharique lab2 solution.ipynb**: Solution notebook with finalized code and observations.

## Key Concepts
- Thread creation and management.
- Synchronization primitives (optional depending on specific tasks).
- Performance overhead of threading in Python (GIL limitations).

## Requirements
- Python 3.x
- Jupyter Notebook or JupyterLab
- `threading` and `time` libraries (standard library).
